# Sistema de Controle de Despesas

Projeto de estudo em Java 21 para organizar despesas pessoais.

---

## Funcionalidades

- Criar despesas com descrição, valor, data e categoria.
- Validar os dados das despesas.
- Calcular o total de despesas de um mês e ano.
- Agrupar despesas por categoria.
- Filtrar despesas por categoria ou por período.
